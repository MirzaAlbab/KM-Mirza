# KM-Mirza

A week-by-week collection of Kampus Merdeka / Binar Academy programming exercises and mobile-development projects.

[Repository](https://github.com/MirzaAlbab/KM-Mirza)

## Features

- JavaScript fundamentals, algorithms, loops, and functions
- React and React Native exercises
- Todo, API, movie, and Firebase examples
- Selected projects with CI/CD configuration

## Getting started

```bash
git clone https://github.com/MirzaAlbab/KM-Mirza.git
cd KM-Mirza
```

Choose a week/day exercise and inspect its files. For a nested project with `package.json`, change into that project's directory, install its dependencies with the package manager used there, and run a script defined in its manifest.

React Native exercises require their own compatible Android/iOS development environments; simple HTML exercises can be opened through a local static server.

## Development and checks

Run checks from the individual exercise directory. Some nested projects contain Jest files and CI workflows; there is no root test command.

## Project notes

Each nested project has its own dependencies and scripts. There is no single root application or root package.json.
